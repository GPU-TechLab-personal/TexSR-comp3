# Shared vs split networks: `matup_shared_vs_split/ep10`, 12 MatSynth evaluation materials

docs/SPLIT_THEORY.md D. x4 (128 -> 512). Generated by variants/eval/evaluate.py.

- **Height**: every arm is rendered with the **GT height** (no split arm predicts
  height; the shared DeepTex arm's SR height and MatUp's LR-height displacement are
  not used). Only the MatUp self-check renders with MatUp's own LR height.
- **Crop**: every arm and the GT are cropped by MatUp's border (8 px, measured on the
  MatUp _opt maps as comp1 did); render metrics also skip GT-invalid normals
  (|2v-1| < 0.1 or unit n_z < 1e-3).
- **Map metrics**: PSNR / SSIM on the stored maps rounded to 8 bit on both sides
  (texsr_metrics; MatUp writes 16 bit, the GT and DeepTex 8 bit). baseColor in sRGB,
  roughness / metallic raw ([0,1]; MatUp's roughness_opt is sqrt(alpha)). Normal MAE:
  mean angle between the decoded unit normals, GT-valid texels. bilinear's maps
  here are cv2.INTER_LINEAR of the stored LR PNGs; its renders use MatUp's own
  initialisation (decode at 128, then bilinear, normal rebuilt from XY).
- **Render metrics**: MatUp's torch renderer, display values (Reinhard + gamma).
  train100 = MatUp's 1.4 x fib(100) training lights; held-out = EVAL_LIGHT +
  1.4 x fib(16) turned 43.25 deg (17 lights, >= 2.89 deg from every training light).
  PSNR: MSE over texels x lights x RGB. l2,1: MatUp's loss (mean RGB L2 norm per
  texel-light), lower is better.
  LPIPS-alex over the heldout lights, FLIP (LDR) over the sheet lights, on the same renders;
  baseColor LPIPS on the stored sRGB map. Lower is better for all three.
- **Compensation** (SPLIT_THEORY C-1): l2,1 of the GT material with only group g's
  SR maps swapped in (a = baseColor, n = normal, rm = roughness + metallic), next to
  the full-SR l2,1. full / sum < 1 means the groups' render errors partly cancel.
- **MatUp seeds** are shown individually and as mean ± std (ddof 1) of the per-seed means.
- Means are over the **12 common materials** (every listed arm scored); a cell's
  (n=k) means k of them had a finite value (an identical 8-bit map has PSNR = inf).

Arms: `bilinear` = bilinear; `matup_shared_s0` = MatUp shared MLP s0; `matup_shared_s1` = MatUp shared MLP s1; `matup_shared_s2` = MatUp shared MLP s2; `matup_split_s0` = MatUp split MLP s0; `matup_split_s1` = MatUp split MLP s1; `matup_split_s2` = MatUp split MLP s2; `matup_split_x1_s0` = MatUp split MLP 1x s0; `matup_split_x1_s1` = MatUp split MLP 1x s1; `matup_split_x1_s2` = MatUp split MLP 1x s2; `matup_split_x3_s0` = MatUp split MLP 3x s0; `matup_split_x3_s1` = MatUp split MLP 3x s1; `matup_split_x3_s2` = MatUp split MLP 3x s2; `matup_shared_noreg_s0` = MatUp shared MLP, no metallic reg s0; `matup_shared_noreg_s1` = MatUp shared MLP, no metallic reg s1; `matup_shared_noreg_s2` = MatUp shared MLP, no metallic reg s2; `matup_split_noreg_s0` = MatUp split MLP, no metallic reg s0; `matup_split_noreg_s1` = MatUp split MLP, no metallic reg s1; `matup_split_noreg_s2` = MatUp split MLP, no metallic reg s2; `matup_shared_zinit_s0` = MatUp shared MLP, zero-init last layer s0; `matup_shared_zinit_s1` = MatUp shared MLP, zero-init last layer s1; `matup_shared_zinit_s2` = MatUp shared MLP, zero-init last layer s2; `matup_split_zinit_s0` = MatUp split MLP, zero-init last layer s0; `matup_split_zinit_s1` = MatUp split MLP, zero-init last layer s1; `matup_split_zinit_s2` = MatUp split MLP, zero-init last layer s2.
