TexSR-comp3 실행 명령어 모음 (연구실 PC: Windows + RTX 5090)
=====================================================================
맵 그룹 분할 실험 (docs/SPLIT_THEORY.md). 명령은 전부 "Git Bash"에서, 레포 폴더(TexSR-comp3)에서 실행합니다.
오래 걸리는 단계는 컨테이너로 따로 떠서 돌기 때문에 Git Bash 창이나 원격 데스크톱을 닫아도 계속 진행됩니다.
Docker 메모리 설정, Windows 업데이트 재부팅 막기 등 PC 준비는 comp2 COMMANDS.txt [0]과 같습니다.


[1] 코드 받기
---------------------------------------------------------------------
# 서브모듈(DeepTextures, esrgan-tf2, MatUp, KAIR)까지 같이 받음
git clone --recursive https://github.com/GPU-TechLab-personal/TexSR-comp3.git
cd TexSR-comp3

# 데이터 위치 설정 (기본값 DATA_ROOT=D:/ -> D:\MatSynth, D:\TexSR-data)
cp docker/.env.example docker/.env


[2] 환경 설치 (이미지 빌드 + 가중치 + GPU 확인)
---------------------------------------------------------------------
# 실패하거나 끊겨도 같은 명령을 다시 실행하면 이어서 진행. 끝에 OK / FAILED 요약
#   data      dataprep 이미지
#   deeptex   deeptex 이미지 (TF 2.10). 처음 한 번 5090용 커널을 즉석 컴파일함 (7~10분 멈춘 것처럼 보임, 정상)
#   matup     MatUp SwinIR-L 가중치 + matup 이미지 (lpips, flip 포함)
mkdir -p runs/logs && bash scripts/setup.sh 2>&1 | tee -a runs/logs/setup.log


[3] 데이터 - 앞으로 데이터는 전부 D:\TexSR-data 에 둡니다 (레포 안에 두지 않음)
---------------------------------------------------------------------
# D:\TexSR-data\
#   matsynth\                          평가 재질 12개 (LR 입력 + 512 GT)
#   datasets\matsynth\                 512/128 학습 쌍
#   deeptex\matsynth_grouped\          grouped TFRecord (+ verify_report.json)
#   checkpoints\deeptex_renloss_21\    공유 기준 모델 체크포인트 (comp2에서 학습한 것)

# 3-1 comp2가 만든 데이터를 복사 (robocopy, 끊기면 다시 실행하면 이어서)
#     인자는 comp2 레포 폴더 경로
bash scripts/data.sh import ../TexSR-comp2

# 3-2 복사본 검증: 학습 쌍 열화 == 평가 열화 [PASS], grouped TFRecord 바이트 검증 PASS
bash scripts/data.sh verify

# 상태 (무엇이 D:\TexSR-data 에 있는지)
bash scripts/data.sh status

# (comp2 데이터가 없을 때만) MatSynth에서 새로 만들기: evalset -> check -> pairs -> grouped
#   bash scripts/data.sh evalset
#   bash scripts/data.sh check
#   bash scripts/data.sh pairs        (1시간 안팎, 백그라운드)
#   bash scripts/data.sh grouped      (백그라운드)


[4] DeepTex 분할 학습 (세 네트워크 공동 학습, nb=23 / nb=7)
---------------------------------------------------------------------
# 4-1 분할 수식 검사 (CPU, 1분): gradient 분리/공동학습 식, 파라미터 수, 그룹 묶기. 끝에 OK
bash scripts/deeptex_split.sh test

# 4-2 파라미터 수 확인 (nb23: 16,697,987 x 3, nb7: 5,187,203 x 3, 끝에 OK 표시)
bash scripts/deeptex_split.sh params

# 4-3 200 step 시험 학습 (끝에 EXIT 0, [metrics]의 steps_per_sec / gpu_mem_mb 확인)
bash scripts/deeptex_split.sh smoke nb23
bash scripts/deeptex_split.sh smoke nb7

# 4-4 본 학습 40k step - 한 번에 하나씩 (끊기면 다시 실행 -> 마지막 체크포인트부터)
bash scripts/deeptex_split.sh train nb23
bash scripts/deeptex_split.sh train nb7

# 진행 상황 / 로그 / 중지
bash scripts/deeptex_split.sh status
tail -f runs/logs/deeptex_split_nb23_train.log
tail -f runs/logs/deeptex_split_nb7_train.log
bash scripts/deeptex_split.sh stop train nb23
bash scripts/deeptex_split.sh stop train nb7

# 4-5 배치 비교: nb7을 재질 8개/step으로 (네트워크마다 업데이트당 8장, 기존은 2장)
#     40k step이라 nb7보다 데이터를 4배 더 봄 -> nb7(B=2)과 비교해 배치 효과를 봄
#     먼저 smoke로 메모리/속도 확인 (OOM이면 yaml의 render.light_chunks: 4)
bash scripts/deeptex_split.sh smoke nb7b8
bash scripts/deeptex_split.sh train nb7b8
tail -f runs/logs/deeptex_split_nb7_b8_train.log
bash scripts/deeptex_split.sh stop train nb7b8
#     끝나면 [6] 평가를 다시: infer -> montage -> score (새 arm "DeepTex split nb7 x3 B=8"이 추가됨)

# 4-6 RM 손실 수정: RM 네트워크의 pixel/VGG/D 손실을 [0,R,M] 묶음 이미지가 아니라
#     회색 roughness, 회색 metallic 이미지로 계산 (공유 모델과 같은 방식, w_rm 25)
#     배치 2, seed 1, 40k로 기존 nb23 / nb7과 짝이 맞음. 먼저 4-1 test (rm grey 검사 포함)
bash scripts/deeptex_split.sh test
bash scripts/deeptex_split.sh smoke nb7grey
bash scripts/deeptex_split.sh train nb7grey
bash scripts/deeptex_split.sh train nb23grey
tail -f runs/logs/deeptex_split_nb7_rmgrey_train.log

# (comp2 체크포인트를 못 가져왔을 때만) 공유 기준 모델 재학습 - comp2와 같은 설정
#   bash scripts/deeptex_split.sh train shared
#   이때 체크포인트는 runs/deeptex/deeptex_renloss_21/checkpoints/esrgan_40k (평가 때 경로 지정)


[5] MatUp 공유 / 분할 MLP (평가 재질 12개 x seed 3개)
---------------------------------------------------------------------
# DeepTex 학습과 같이 돌려도 되지만 느려짐. VRAM이 부족하면 하나씩
# 5-1 SplitMLP 검사 (파라미터 수 309,511 / 408,839, 1배 309,719 / 3배 927,302, 채널 분리). 끝에 OK
bash scripts/matup_split.sh test

# 5-2 재질마다 LR 렌더 + SwinIR-L x4 렌더를 한 번만 만들어 캐시 (백그라운드, 재질당 1분 안팎)
bash scripts/matup_split.sh prep

# 5-3 최적화: 12 재질 x arm x seed {0,1,2} (백그라운드, 회당 1~2분)
#     arm: matup_shared, matup_split (폭 128, 1.32배), matup_split_x1 (폭 104, 1.00배),
#          matup_split_x3 (폭 227, 3.00배), noreg (5-4), zinit / st (5-6).
#          기본은 열 개 전부 = 360회
#     끊기면 다시 실행 -> 끝난 run은 건너뜀 (이미 끝난 shared / split 72회는 건너뜀)
bash scripts/matup_split.sh optim
#     파라미터 맞춘 두 arm만: bash scripts/matup_split.sh optim matup_split_x1,matup_split_x3

# 5-4 metallic 정규화 끄기 (alpha_reg 0): 공유 / 분할(폭 128) 모두, 나머지는 같은 설정·같은 seed
#     -> 정규화항이 채널 사망(clamp 경계에 붙음)의 원인인지 확인 (SPLIT_THEORY B1-4). 72회, 45분 안팎
#     12 재질 전부 돌려야 평가 표의 평균(12 재질 공통)이 줄지 않음
bash scripts/matup_split.sh optim matup_shared_noreg,matup_split_noreg
#     끝나면 [6] 평가: score matup/ep10, montage matup/ep10 --seeds 0,1,2

# 5-5 채널 사망 계측 (docs/CLAMP_DEATH.md E1): shared / split을 epoch마다 clamp 통계를 찍으며 다시 실행
#     -> runs/matup_split/probe/ (평가 arm 아님, 기존 결과는 그대로). 72회, 50분 안팎
#     optim과 컨테이너가 달라 같이 돌려도 되지만 느려짐
bash scripts/matup_split.sh probe
tail -f runs/logs/matup_split_probe.log      # [probe] <tag>: dead ... 줄로 epoch별 죽은 채널 확인

# 5-6 수정안 (CLAMP_DEATH.md E2): 마지막 층 0 초기화(zinit), straight-through clamp(st), 공유·분할 모두
#     probe 포함. 144회, 1.5시간 안팎. 끝나면 [6] 평가 (score / montage matup/ep10)
bash scripts/matup_split.sh optim matup_shared_zinit,matup_split_zinit,matup_shared_st,matup_split_st

# 5-7 probe 표: probe.json 전부 -> runs/eval/matup_clamp_probe/ep10/{summary.md,report.json} (몇 초, git에 올라감)
bash scripts/matup_split.sh report

# 진행 상황 / 로그 / 중지
bash scripts/matup_split.sh status
tail -f runs/logs/matup_split_optim.log
bash scripts/matup_split.sh stop optim
bash scripts/matup_split.sh stop probe


[6] 평가 (평가 재질 12개, 모든 arm)
---------------------------------------------------------------------
# 결과 폴더: 실험별 폴더 아래 체크포인트 폴더 (명령의 RUN = <실험>/<체크포인트>)
#   runs/eval/deeptex_shared_vs_split/30k|35k|40k/   DeepTex: bilinear, 공유 renloss_21, 분할 arm (그 step의 체크포인트)
#   runs/eval/matup_shared_vs_split/ep10/            MatUp: bilinear, 공유 / 분할 MLP s0-s2 (재질별 10 epoch 최적화)
#   각 폴더: report.json, summary.md, montage/{overview,material,zoom}/  (git에 올라감) + maps/ (안 올라감)
#   명령에서는 deeptex/40k, matup/ep10 처럼 줄여 써도 됨. 한 단계씩 EXIT 0 확인 후 다음
#   공유 renloss_21은 체크포인트가 하나뿐이라 30k/35k/40k 폴더 모두 같은 모델 (짝 비교 기준)

# 6-1 DeepTex 추론: 폴더 이름의 step으로 분할 arm 체크포인트를 고름 (40k -> step 40000)
#     끝 줄 written: 에 분할 arm들이 있어야 함
bash scripts/eval.sh infer deeptex/40k
bash scripts/eval.sh infer deeptex/35k
bash scripts/eval.sh infer deeptex/30k

# 6-2 몽타주 - 육안 비교 (6-1 다음, score 없이 가능. 백그라운드, 몇 분). 파일 이름 앞에 실험 이름
#     overview/<실험>_overview_<맵>.png  재질 12개 x arm 한 장 (baseColor/normal/roughness/metallic/render/error)
#                                         -> 먼저 이것부터 보기
#     material/<실험>_<재질>.png         열: baseColor normal roughness metallic | 렌더 EVAL / grazing | |렌더-GT| x4 (+PSNR)
#     zoom/<실험>_<재질>_zoom.png        노란 박스 영역(디테일이 가장 많은 96x96 texel)을 확대한 것
bash scripts/eval.sh montage deeptex/40k
bash scripts/eval.sh montage matup/ep10
#     MatUp seed 전부: bash scripts/eval.sh montage matup/ep10 --seeds 0,1,2
#       -> montage/by_seed/s0,s1,s2/ 에 seed별 sheet도 같이 생김 (GT, bilinear + 그 seed의 arm만)
#     git으로 받은 sheet를 seed별로 자르기만: bash scripts/eval.sh split matup/ep10  (몇 초)
#     줌 위치 직접 지정 (crop 좌표 y,x): bash scripts/eval.sh montage deeptex/40k --zoom 64 --zoom-at 200,120 --material <재질>

# 6-3 지표 계산: 맵 PSNR/SSIM/normal 각도, 렌더 PSNR/l2,1/LPIPS/FLIP (모든 arm height = GT)
bash scripts/eval.sh score deeptex/40k
bash scripts/eval.sh score matup/ep10

# 진행 상황 / 중지
bash scripts/eval.sh status
bash scripts/eval.sh stop score

# (한 번만) 예전 이름 runs/eval/main, step30k, step35k의 maps/를 새 폴더로 옮김 (git pull 후)
bash scripts/eval.sh migrate

# 결과를 다른 PC로 (.gitignore가 report.json, summary.md, montage/만 올림. maps/는 안 올라감)
# external/matup_egsr (untracked content) 표시는 SwinIR 가중치 등이라 add 하지 않음
git add -A runs/eval && git commit -m "split results" && git push

runs/deeptex/deeptex_split_nb7/checkpoints/        분할 nb=7 체크포인트
